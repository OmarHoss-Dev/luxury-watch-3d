# Aurelian Genève · Meridian 41 — 3D Luxury Watch

An interactive 3D luxury watch showcase built with three.js. The watch rotates smoothly, zooms into parts on hover, lets you click any part to inspect it, and comes apart into an exploded view that reassembles as you scroll.

**Live site:** https://omarhoss-dev.github.io/luxury-watch-3d/

Single `index.html`, no build step — open it in a browser or serve the folder.
